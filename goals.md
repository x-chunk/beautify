# Goals

Work that is intentionally left out of the first version. `plan.md` covers
the first version; nothing in this file is part of it. The design in
`plan.md` must not block any item in "Deferred".

## Deferred

### Redraw and live output

Progress bars, spinners and trees that update in place. This needs cursor
control and per-output state (how many lines the previous frame occupied).

Constraints that keep it possible:

- Only `Composer` writes to the `io.Writer`, so cursor state has a single
  owner.
- `dra.Engine` stays stateless. Redraw is built on top of it: the state
  lives in `Composer` or in a dedicated type next to it.
- `Model` exposes `Height`, which is what a redraw needs to move the cursor
  back.

### Full Unicode conformance for Long Mode

The first version of Long Mode uses a simplified grapheme segmentation
built on the standard `unicode` tables plus a hand-written list of wide
ranges. The full version follows UAX #29 (grapheme clusters) and UAX #11
(East Asian Width) with tables generated by `go generate` from the official
Unicode data files into `internal/`. The generator is a development-time
tool only; the library keeps zero runtime dependencies.

Known gaps of the simplified version to close here:

- Some symbols inside the coarse emoji blocks are narrow by the standard
  but measured as wide.
- Hangul syllable composition is approximated.
- Ambiguous-width characters are always measured as narrow.

### Enabling ANSI output on the Windows console

On Windows, virtual terminal processing has to be switched on for the
legacy console. The first version does not do this: it emits styles on
Windows only when the environment indicates a capable terminal, and
otherwise falls back to plain output. An explicit profile option always
works.

### Semantic themes

Named styles such as "primary", "muted", "error" and "border" that blocks
resolve at render time, so one setting restyles every block. In the first
version blocks take explicit `dra.Style` values and default to inheriting.

### Terminal width on more platforms

The first version queries the terminal width on Linux, macOS and the BSDs.
Other platforms fall back to the `COLUMNS` variable and then to unbounded
width.

## Out of scope for now

- A `log/slog` adapter. It can be revisited as a separate subpackage once
  the core is stable. The core must not be shaped around it.

## Non-goals

Deliberate decisions. See `AGENTS.md`.

- Overlaying blocks and absolute positioning.
- A flexbox-style layout engine.
